# 图片笔记小程序 — AI 设计稿生成输入文档

> 用途：提供给 AI 设计工具（如 Figma AI、Motiff 等）生成小程序 UI 设计稿的结构化输入。
> 版本：V1.0.0
> 目标平台：微信小程序（移动端，iOS/Android）
> 设计基准：iPhone 14/15 屏幕（375×812 pt），适配安全区域

---

## 一、产品一句话概述

一款个人图片笔记小程序。用户拍照或从相册选图上传，为图片添加文字备注和个人标签，按图片、备注、标签三个维度回看内容。核心体验：图片优先、记录轻量、主题整理。

---

## 二、设计哲学与视觉基调

### 2.1 产品气质关键词

- **轻盈**：不厚重、不复杂，减少视觉负担
- **务实**：以内容（图片）为主体，UI 退后
- **私密**：个人日记本的感觉，不喧闹、不社交
- **聚焦**：每次只做一件事，减少干扰元素

### 2.2 视觉风格方向建议

| 维度 | 建议方向 |
|---|---|
| 整体风格 | 极简主义，大量留白，以图片内容为视觉重心 |
| 色彩倾向 | 中性色为主，品牌色点缀，不抢图片风头 |
| 圆角 | 适中圆角（卡片 8-12px，按钮 6-8px），柔和但不幼稚 |
| 阴影 | 轻阴影或无阴影，扁平化为主 |
| 图标 | 线性图标为主，简洁统一，24px 基准 |
| 字体 | 系统默认中文字体（PingFang SC），层次通过字重和大小区分 |

### 2.3 色彩系统建议

| 角色 | 色值建议 | 用途 |
|---|---|---|
| 品牌主色 | `#4F46E5`（Indigo）或 `#0891B2`（Cyan） | 主按钮、选中态、Tab 激活态 |
| 品牌浅色 | 主色 10% 透明度 | 标签选中背景、高亮背景 |
| 文字主色 | `#1A1A1A` 或 `#111827` | 标题、正文 |
| 文字次色 | `#6B7280` 或 `#999999` | 辅助信息、时间戳 |
| 文字弱色 | `#9CA3AF` 或 `#BFBFBF` | 占位文本、禁用态 |
| 背景主色 | `#F5F5F5` 或 `#F9FAFB` | 页面背景 |
| 背景卡片 | `#FFFFFF` | 卡片、列表项、编辑层 |
| 分割线 | `#E5E7EB` 或 `#EEEEEE` | 分割线、边框 |
| 成功/正向 | `#10B981` | 上传成功、保存成功 |
| 错误/警告 | `#EF4444` | 删除按钮、错误提示、失败标记 |
| 警告/提醒 | `#F59E0B` | 空间预警 |

### 2.4 字体层级建议

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| H1 页面标题 | 18px | Bold (600) | 导航栏标题 |
| H2 区域标题 | 16px | Medium (500) | 区块标题 |
| Body 正文 | 15px | Regular (400) | 备注内容、标签名称 |
| Caption 辅助 | 13px | Regular (400) | 时间、标签数量、字数统计 |
| Small 弱化 | 11px | Regular (400) | 次要标注 |
| Button 按钮 | 15px | Medium (500) | 按钮文字 |

### 2.5 间距系统

建议使用 4px 基准间距体系：

- **xs**: 4px（紧凑元素间距）
- **sm**: 8px（标签间距、图标与文字间距）
- **md**: 12px（卡片内边距、列表项间距）
- **lg**: 16px（页面左右边距、区块间距）
- **xl**: 20px（大区块间距）
- **2xl**: 24px（页面顶部间距、底部操作区间距）

## 三、信息架构与导航结构

### 3.1 导航结构

```
底部 TabBar（2 个一级入口）
├── 图片（默认 Tab，图标：图片/相册图标）
└── 备注（图标：笔记/列表图标）

二级页面（从一级页面推入，隐藏 TabBar）
├── 图片预览详情（从图片列表点击进入）
├── 标签管理（从标签筛选区进入）
├── 设置与隐私（从导航栏设置图标进入）
└── 注销处理中（受限状态页）

底部面板 / 操作层（覆盖在当前页面上方）
├── 图片选择与上传面板
├── 备注编辑层
└── 标签选择与创建层
```

### 3.2 核心用户流

```
启动 → 身份建立 → 图片列表（默认全部图片）
  ├── 添加图片 → 来源选择 → 上传面板 → 图片列表
  ├── 点击图片 → 图片预览详情
  │     ├── 添加/编辑备注 → 备注编辑层
  │     ├── 添加/编辑标签 → 标签选择层
  │     └── 删除图片 → 确认弹窗 → 返回列表
  ├── 切换标签筛选 → 筛选后的图片列表
  ├── 点击管理/更多 → 标签管理页
  └── 点击设置 → 设置与隐私页 → 注销流程
```

## 四、逐页设计规格

### 4.1 PG-001 启动页

**页面类型**：启动流程页
**出现时机**：冷启动或会话失效时

**设计要素**：
- 居中品牌标识：App 图标 + "图片笔记" 文字（约 80px 图标 + 下方 20px 产品名）
- 加载指示器：品牌色旋转加载或骨架屏
- 底部版本号（弱化）
- 失败态：错误图标 + "登录失败，请重试" + 品牌色重试按钮

**背景**：纯白或浅灰底色，无多余装饰

---

### 4.2 PG-002 图片列表（核心页面）

**页面类型**：一级 Tab 页，带底部导航
**布局结构**（从上到下）：

```
┌─────────────────────────────┐
│  状态栏（系统）               │
├─────────────────────────────┤
│  "图片" 标题     [设置图标]   │  ← 导航栏，避开胶囊区域
├─────────────────────────────┤
│  [全部] [未分类] [标签A] ...  │  ← 横向滚动标签筛选区
│  [更多▾]                     │  ← 自适应入口
├─────────────────────────────┤
│  ⚠ 空间即将用满，请清理...    │  ← 条件显示的空间预警条
├─────────────────────────────┤
│  ┌───────┐ ┌───────┐       │
│  │       │ │  📝2  │       │  ← 两列瀑布流网格
│  │ 图片1  │ │       │       │     图片保持比例
│  │       │ │ 图片2  │       │     备注标记在固定角落
│  └───────┘ └───────┘       │
│  ┌───────┐ ┌───────┐       │
│  │  📝5  │ │       │       │
│  │ 图片3  │ │ 图片4  │       │
│  └───────┘ └───────┘       │
├─────────────────────────────┤
│                             │
│     [+ 添加图片] 悬浮按钮     │  ← FAB 主操作按钮
│                             │
├─────────────────────────────┤
│   📷 图片    │    📝 备注    │  ← 底部 TabBar
└─────────────────────────────┘
```

**详细设计规格**：

**导航栏**
- 高度：44px（不含状态栏）
- 左侧标题 "图片"，18px Bold
- 右侧设置图标（齿轮/三条线图标），24px，避开微信胶囊
- 背景：白色，底部可选 1px 分割线

**标签快捷筛选区**
- 高度：约 40px
- 横向单行布局，可左右滑动
- 固定在前：【全部】【未分类】（始终显示）
- 选中态：品牌色填充胶囊，白色文字
- 未选中态：灰色描边或浅灰背景胶囊
- 操作入口（管理/更多/＋新建标签）：图标 + 文字，弱化样式以区分
- 标签名称超出时单行省略号
- 间距：胶囊之间 8px，左右边距 16px

**空间预警条**
- 条件显示（空间 ≥ 85%）
- 黄色/橙色背景条，警告图标 + 文字
- 高度约 36px，可关闭
- 每会话最多出现一次

**图片网格**
- 两列等宽布局，列间距 4-8px
- 图片按原始比例显示（瀑布流）
- 卡片圆角 8px
- 备注标记：右下角固定位置
  - 0 条：不显示
  - 1 条：仅显示备注图标（小笔记图标）
  - ≥2 条：图标 + 数字（超过 99 显示 "99+"）
  - 标记需有足够对比度（半透明深色背景 + 白色图标/文字）

**FAB 主按钮**
- 位置：右下角悬浮，距离底部 TabBar 约 16-24px
- 圆形按钮，品牌色填充，白色 "+" 图标
- 尺寸：56×56px
- 可选微阴影
- 点击展开 "从相册选择" / "拍照" 选项（底部 ActionSheet 样式）

**底部 TabBar**
- 两个 Tab：图片（选中态）、备注
- 图标 + 文字标签
- 选中态：品牌色图标 + 文字
- 未选中态：灰色图标 + 文字

**状态覆盖**：
- **加载态**：灰色骨架块代替图片卡片，保持网格布局
- **刷新态**：顶部刷新指示器，现有内容不动
- **空态（全部）**：居中插图 + "还没有图片" + "添加第一张图片" 按钮
- **空态（未分类）**：居中插图 + "所有图片都已添加标签"
- **空态（用户标签）**：居中插图 + "这个标签下还没有图片" + "查看全部图片" 链接
- **错误态**：居中错误图标 + "图片加载失败，点击重试"
- **标签加载失败**：标签区显示 "标签加载失败，重试" 文字链接

### 4.3 PG-003 图片选择与上传面板

**页面类型**：底部面板（覆盖在 PG-002 上方，可下滑关闭）
**高度**：约占屏幕 70%-85%

**布局结构**（从上到下）：

```
┌─────────────────────────────┐
│  已选 N/20        [继续选择] │  ← 顶部操作栏
├─────────────────────────────┤
│  网格展示已选图片（每行 3-4 张） │  ← 图片预览区，可滚动
│  ┌────┐ ┌────┐ ┌────┐     │
│  │缩略│ │缩略│ │缩略│     │     每张显示：
│  │ ✓  │ │85% │ │ ✗  │     │     - 本地缩略图
│  └────┘ └────┘ └────┘     │     - 状态标识（成功✓/失败✗/进行中）
│  ┌────┐ ┌────┐            │     - 进度条（上传中）
│  │缩略│ │缩略│            │     - 失败原因（失败时）
│  └────┘ └────┘            │
├─────────────────────────────┤
│  ⚠ 失败提示（如有失败任务）    │
├─────────────────────────────┤
│  [ 开始上传 ]               │  ← 主按钮（未开始上传时）
│  成功 N 张，失败 M 张        │  ← 结果区（上传结束后）
│  [为本批图片添加标签] [完成]  │  ← 标签入口 + 完成（上传结束后）
└─────────────────────────────┘
```

**关键交互**：
- 未上传图片可移除（左滑删除 或 长按 × 图标）
- 失败图片显示红色标记 + 失败原因（格式不支持、文件过大、网络错误等）
- 上传进行中：每个任务独立显示进度（0%→100%）
- 离开面板时的确认弹窗（非成功任务将被取消）
- 上传成功后跳变绿色 ✓
- 标签添加按钮仅在全部任务结束 + 至少 1 张成功时出现

**页面类型**：二级页面（从 PG-002 推入）

**布局结构**（从上到下，可滚动）：

│                             │
├─────────────────────────────┤

├─────────────────────────────┤

│  ┌──────┐ ┌──────┐         │

│  │           [编辑][删除] │   │     创建时间

│  ┌─────────────────────┐   │
│  │ ……                   │   │

└─────────────────────────────┘
```

**设计细节**：
- 图片背景深色，突出图片内容
- 图片与信息区之间有自然过渡
- 标签区位于拍摄时间与备注区之间
- 标签胶囊：品牌色 10% 背景 + 品牌色文字，圆角 12px
- 备注卡片：白色背景，8px 圆角，内边距 12px，卡片间距 8px
- 编辑/删除操作折叠在每个备注卡片右下角
- 备注高亮动画：从备注列表跳入时，目标备注区域短暂（约 2 秒）高亮（浅黄色背景过渡）
- "添加备注" 按钮：底部固定，品牌色，宽度撑满（距边距 16px）
- 删除图片入口：导航栏 "更多操作"（···）菜单中

**状态**：
- 图片加载中：居中旋转加载
- 图片加载失败：灰色图片占位 + "重新加载"
- 图片不存在：错误提示 + 自动返回列表
- 无备注：插图 + "还没有备注，记录此刻的想法"
- 标签加载失败：标签区显示 "标签加载失败，重试"

```

**设计细节**：
- 标准 iOS 设置列表风格：白色卡片 + 分割线
- 空间用量使用进度条可视化
- "注销账号" 使用红色/警告色，置于页面底部独立区域
- 间距：分组间 16px

**注销流程弹窗**：
1. 首次确认：展示注销影响范围 + "确认注销" / "取消"
2. 文字二次确认：输入框 + "请输入完整的'确认注销'" + 提交按钮（输入正确前禁用）

## 五、通用组件模式

### 5.1 Toast 提示
- 位置：屏幕中上方或底部
- 样式：深色半透明背景 + 白色文字
- 图标 + 文案（如 ✓ 保存成功）
- 持续约 1.5-2 秒自动消失

### 5.2 确认弹窗（Modal）
- 居中白色卡片，圆角 12px
- 标题（16px Bold）
- 正文（14px Regular，灰色）
- 两个按钮横向排列：取消（左，灰色）+ 确认（右，红色/品牌色）
- 蒙层：rgba(0,0,0,0.5)

### 5.3 ActionSheet
- 从底部滑入的选项面板
- 选项列表 + 取消按钮
- 危险操作用红色文字

### 5.4 骨架屏
- 灰色闪烁块
- 保持与真实内容相同的布局和尺寸
- 图片区域用浅灰矩形占位
- 文字区域用浅灰条占位

### 5.5 空态插图
- 居中轻量插画/图标（灰色调）
- 主文案（15px，灰色）
- 可选操作按钮（品牌色）
- 不传达错误感，传递"等待开始"的温和感受

### 5.6 标签胶囊（Tag Chip）
- 品牌色 10% 背景 + 品牌色文字
- 圆角 12px
- 内边距：上下 4px，左右 10px
- 字号：13px
- 关闭图标（可选）：× 图标

### 5.7 备注标记徽章
- 固定在图片卡片右下角
- 半透明深色背景（rgba(0,0,0,0.55)）
- 白色图标 + 数字
- 圆角 4px，内边距 2px 6px
- 最小宽度：仅图标时约 20px，有数字时自适应

## 六、关键交互规格

### 6.1 页面转场
- 一级→二级：右向左推入（iOS 标准 push）
- 底部面板：从下向上滑入 + 蒙层淡入
- Modal：居中缩放出现 + 蒙层淡入

### 6.2 下拉刷新
- 列表页标准下拉刷新
- 刷新时保留现有内容，差量更新
- 不整页清空或闪白

### 6.3 触底加载
- 接近列表底部 200px 时自动触发
- 底部显示加载指示器
- 无更多数据时显示 "— 没有更多了 —"

### 6.4 图片手势
- 图片预览支持双指缩放（pinch zoom）
- 支持拖动查看（pan）
- 缩放范围：1x ~ 3x

### 6.5 备注高亮动画
- 从备注列表跳入图片详情时
- 目标备注区域背景色：白色 → 浅黄色 → 白色
- 过渡时间约 2 秒

### 6.6 按钮状态
- 默认态：品牌色填充
- 按下态：品牌色加深 10%
- 禁用态：灰色填充（#D1D5DB），灰色文字
- 加载态：按钮内显示 spinner + 文字变灰

### 6.7 保存防重复
- 保存按钮点击后立即禁用
- 显示加载态
- 成功/失败后恢复
