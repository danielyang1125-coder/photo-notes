> 原型文件：[PROTOTYPE-图片笔记小程序-V1.0.0.html](./PROTOTYPE-图片笔记小程序-V1.0.0.html)  
> 设计系统：[DESIGN-SYSTEM-图片笔记小程序-V1.0.0.md](./DESIGN-SYSTEM-图片笔记小程序-V1.0.0.md)

## 1. 原型说明

这是一个单文件、无外部依赖的中高保真交互原型，已合并标签功能增量。桌面浏览时左侧为评审导航，右侧模拟 375 × 812 px 微信小程序视口；窄屏打开时自动切换为全屏手机模式。

HTML 使用与 TDesign 微信小程序一致的视觉和交互模式进行模拟。实际开发时，应使用下表标注的真实 `t-*` 组件，不复制原型 CSS 作为生产组件库。

## 3. 主流程

1. PG-002 点击悬浮添加按钮。
2. ActionSheet 选择“从相册选择”，打开 PG-003。
3. 点击“开始上传”，观察任务进度与失败项重试；任务完成后点击“为本批图片添加标签”，在 PG-010 选择并保存。
4. 返回 PG-002，使用【全部】【未分类】或用户标签进行单选筛选。
5. 点击图片进入 PG-004，在标签区点击“编辑”，于 PG-010 添加或移除标签。
6. 返回 PG-002，点击“更多”进入 PG-009，演示按标签筛选、重命名与删除。
7. 在 PG-004 点击“添加备注”，在 PG-005 输入并保存。
8. 切换到底部“备注”进入 PG-006；点击备注返回 PG-004，原型自动定位并高亮目标备注。

## 4. 页面状态与评审入口

桌面端评审面板提供状态按钮，可快速查看：

- 图片列表：正常、空态、骨架屏、错误态、空间预警。
- 标签筛选：全部、未分类、用户标签空结果、标签加载失败。
- 上传面板：上传中、部分失败、重试成功。
- 图片预览：标签展示、标签编辑、有备注、无备注、目标备注高亮。
- 标签选择：0～5 个选择、达到上限禁用、新建标签、保存失败保留。
- 标签管理：正常、空态、加载、错误、重命名、删除确认。
- 备注编辑：空内容校验、保存失败保留、版本冲突。
- 备注列表：正常、空态、四种排序。
- 注销：影响说明、文字确认、处理中。

## 5. 关键交互约束

- 上传批次最多 20 张，模拟队列中同时最多 3 个任务处于上传状态。
- 关闭存在未完成任务的上传面板必须确认；成功项保留，其他任务取消。
- 备注去除首尾空白后不能为空，最多 1000 个 Unicode code point。
- 保存失败不关闭编辑层，不丢失输入。
- 图片/备注删除明确提示永久删除且不可恢复。
- 注销必须经过影响说明和输入“确认注销”两步确认。
- 高风险 Dialog 不能通过点击遮罩关闭。
- 图片页每次只允许【全部】【未分类】或一个用户标签生效，新会话默认【全部】。
- 快捷标签按最近使用排序；0 个标签显示【＋新建标签】，1～5 个显示【管理】，6～100 个显示【更多】。
- 用户标签名为 1～12 个 Unicode code point；禁用“全部”“未分类”和规范化同名名称。
- 单张图片最多 5 个标签；达到上限时未选项禁用，选中态带勾选标识。
- 标签编辑与批量关联失败时操作层保持打开并保留选择。
- 删除标签只删除标签及关联，不删除图片和备注；删除图片时清理标签关联。

## 6. 开发交接

- 安装并锁定经真机验证的 `tdesign-miniprogram` 版本。
- 按页面局部配置 `usingComponents`。
- `t-upload` 负责选择和任务展示；压缩、EXIF、并发 3、批次累计、取消和幂等重试由业务队列实现。
- 图片列表请求约 200 px 的服务端 `thumbnail_url`；图片预览使用受控预览地址。
- 备注 `updated_at` 由服务端生成并用于乐观并发校验。
- 标签列表与图片首屏并行加载；标签失败不得阻断【全部】图片浏览。
- 标签选择保存采用增量关联，重复提交幂等；批量关联只传当前批次成功入库图片 ID。
