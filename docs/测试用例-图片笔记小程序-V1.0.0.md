## 1. 测试概述

### 1.1 测试策略

| 测试类型 | 覆盖目标 | 执行方式 |
|---|---|---|
| 冒烟测试 | 核心主流程（登录→上传→备注→回看→删除） | 每轮提测优先执行 |
| 功能测试 | 全部功能点正向用例 | 按模块逐项执行 |
| 异常测试 | 网络、权限、服务异常、并发冲突 | 模拟异常环境执行 |
| 边界测试 | 数值上限/下限、字符长度、数量限制 | 按边界值执行 |
| 状态机测试 | 上传任务、用户账号、注销任务状态流转 | 逐状态+非法跳转验证 |
| 集成测试 | 多页面联动、跨设备、数据一致性 | 端到端场景执行 |
| 非功能测试 | 性能、安全、兼容性 | 专项工具+真机 |

### 1.2 优先级定义

| 优先级 | 定义 | 覆盖率要求 |
|---|---|---|
| **P0** | 核心功能，阻塞即不可发布 | 100% 通过 |
| **P1** | 重要功能，影响用户体验 | ≥ 95% 通过 |
| **P2** | 辅助/展示类功能 | ≥ 90% 通过 |

### 1.3 用例编号规则

- `TC-{模块}-{序号}`：唯一标识每条用例
- 关联 AC 编号表示对接 PRD 验收标准
- 关联 BR 编号表示对接 PRD 业务规则
